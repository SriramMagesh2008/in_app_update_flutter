# Code of Conduct

## Our Standards
We expect all contributors to:
- Be respectful
- Use welcoming and inclusive language
- Accept constructive feedback
- Focus on what is best for the community

## Unacceptable Behavior
- Harassment or discrimination
- Offensive or disrespectful comments
- Personal attacks
- Any form of abusive behavior

## Reporting Mechanism
If you experience or witness a violation of this Code of Conduct, please report it by:
- Opening a private issue (if enabled), or
- Contacting the repository maintainers directly via GitHub

All reports will be handled confidentially.

## Enforcement Guidelines
Maintainers are responsible for reviewing and addressing violations. Actions may include:
- Warning the contributor
- Requesting changes or removal of content
- Temporary or permanent ban from contributions

Enforcement decisions will depend on the severity and context of the behavior.

## Scope
This Code of Conduct applies to:
- All repository contributions
- Issues, pull requests, and discussions
- Any community interactions related to this project
